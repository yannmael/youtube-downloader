# Charte visuelle terminal

## Couleurs (codes ANSI)
- Principal : Cyan \033[0;36m
- Succès : Vert \033[0;32m
- Avertissement : Jaune \033[1;33m
- Erreur : Rouge \033[0;31m
- Fond : Terminal par défaut (transparent)

## Style visuel
- Icônes emoji dans les menus (🎬 🎵 📋)
- Bordures avec caractères Unicode (╔ ║ ╚)
- Messages préfixés par [•] [✓] [!] [✗]
- Espacement aéré entre les sections

## Ton
- Français
- Concis et direct
- Messages de confirmation après chaque action
